What is GenAI?

Generative AI Explained

Generative AI creates NEW content (text, images, code, audio, video) by learning patterns from massive datasets. Unlike traditional AI that classifies or predicts, GenAI PRODUCES original output.

  • Text: ChatGPT, Claude, Gemini
  • Images: DALL-E, Midjourney, Stable Diffusion
  • Code: GitHub Copilot, Cursor
  • Video: Sora, Runway
SCRIPT: "Generative AI — the biggest tech trend since the internet. Unsa ni? Unlike traditional AI nga nag-classify or predict, Generative AI nag-CREATE og BAGONG content. Text, images, code, audio, video. ChatGPT, Claude, Gemini — kana sila mag-generate og text. DALL-E, Midjourney — mag-generate og images from text descriptions. GitHub Copilot — mag-write og code for you. Sora — mag-generate og video. Kini nag-change sa every industry. Why? Because creating content — historically expensive and slow — karon, seconds lang. The implications for business, for education, for accounting — massive."

Risks & Ethics

GenAI Risks & Ethical Concerns

  • Hallucinations: AI confidently generates FALSE information. Never trust without verification.
  • Bias: AI learns from biased data → biased outputs. Affects hiring, lending, auditing.
  • Data Privacy: Inputting confidential data into public AI tools = data breach risk.
  • Job Displacement: Some roles will be eliminated. Reskilling needed.
  • Academic Integrity: Students using AI to cheat. Organizations need policies.
  • Deepfakes: Fake videos/audio for fraud, social engineering attacks.
SCRIPT: "But GenAI is not perfect. Serious risks. HALLUCINATIONS — the AI confidently tells you wrong information. I've seen ChatGPT cite fake court cases that don't exist! NEVER trust AI output without verification. BIAS — AI learns from historical data, which is biased. If trained on biased hiring data, it will discriminate. DATA PRIVACY — if you input client financial data into ChatGPT, that data might be used to train the model. Some companies BAN employee use of public AI tools. JOB DISPLACEMENT — real concern. ACADEMIC INTEGRITY — I know some of you use AI for assignments. We'll talk about responsible use. DEEPFAKES — fake videos for fraud. These are REAL risks that IS professionals must address."

Cloud Models

Cloud Service Models: IaaS, PaaS, SaaS

IaaS

Infrastructure as a Service

Rent servers, storage, networking

AWS, Azure, Google Cloud

You manage: OS, apps, data

PaaS

Platform as a Service

Development platform, deploy apps

Heroku, Google App Engine

You manage: Apps, data only

SaaS

Software as a Service

Ready-to-use applications

Gmail, QuickBooks, Shopify

You manage: Nothing (just use it)

For accountants, SaaS is most relevant — cloud accounting, payroll, tax, audit tools you subscribe to monthly.

SCRIPT: "Cloud computing has three main service models. IaaS — Infrastructure as a Service. You rent servers, storage, networking. Like renting a building — you still furnish it yourself. AWS, Azure, Google Cloud. PaaS — Platform as a Service. You get a ready development environment. Just build your app, they handle the infrastructure. SaaS — Software as a Service. Ready-to-use apps. Gmail, QuickBooks Online, Shopify. You just use it, they handle everything. For accountants, SaaS is most relevant — Xero, QuickBooks, MYOB, all SaaS now. You subscribe monthly, access anywhere, always updated. No more installing software from CDs!"

Benefits vs Risks

Cloud Computing: Benefits & Challenges

Benefits ✅

• Cost reduction (no hardware to maintain)
• Scalability (grow/shrink as needed)
• Accessibility (work from anywhere)
• Automatic updates & patches
• Disaster recovery built-in
• Collaboration features

Challenges ⚠️

• Data security & privacy concerns
• Internet dependency
• Vendor lock-in risk
• Compliance (where is data stored?)
• Hidden costs (bandwidth, egress fees)
• Loss of control over infrastructure

SCRIPT: "Cloud is not perfect — naay trade-offs. Benefits: cheaper (no server room needed), scalable (pay for what you use), accessible anywhere, auto-updates, built-in backup, collaboration. But challenges: SECURITY — is your data safe sa someone else's server? INTERNET DEPENDENCY — no internet, no work. VENDOR LOCK-IN — once you're deep in AWS, moving to Azure is painful. COMPLIANCE — kung ang data sa server in the US, under US law ba? Philippine law? HIDDEN COSTS — bandwidth charges surprise many. LOSS OF CONTROL — you depend on the vendor's uptime. These trade-offs, important to evaluate when recommending cloud solutions to clients."

Top Cybersecurity Threats in 2026

Disrupts operations, steals data, and pressures victims through encryption or leak threats.

Improperly set up cloud = exposed data. Common mistake

Zero Trust Security

Zero Trust: Never Trust, Always Verify

Old Model: Castle & Moat

Trust everyone inside the network. One firewall protects everything. Once inside = full access. Problem: if attacker gets in, game over.

New Model: Zero Trust

Trust NO ONE by default. Verify every request regardless of location. Least-privilege access. Continuous authentication. Assume breach has already happened.

Principle: "Never trust, always verify." Every user, device, and request must prove itself — every single time.

SCRIPT: "Zero Trust — the new cybersecurity paradigm. Old model was like a castle with a moat: strong perimeter, but once you're inside, you can go anywhere. Problem: if one person's password gets phished, the attacker has access to EVERYTHING. Zero Trust says: trust NO ONE. Even if you're inside the network, you must verify your identity for every single access. Least-privilege — you only get access to what you SPECIFICALLY need. Continuous authentication — not just login once, but verify throughout. This is critical for organizations with remote workers, cloud systems, and multiple locations. We'll cover Zero Trust in depth in Module 4."
API Economy

The API Economy: Systems Talking to Systems

An API (Application Programming Interface) allows different software systems to communicate with each other automatically. The "API Economy" means businesses create value by connecting systems.

SCRIPT: "APIs — this is how modern systems TALK to each other. Think about it: your QuickBooks is connected to your bank through an API. Transactions automatically flow from bank to accounting system. Your Shopify store connects to QuickBooks through API — every sale automatically recorded. No manual entry! This is the API Economy — businesses create value by CONNECTING systems. As an accountant, you need to understand APIs because they're what make integrated systems possible. You don't need to CODE APIs, but you need to understand HOW they connect systems ug WHAT data flows between them."
